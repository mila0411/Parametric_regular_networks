Файл rgraphs_v3s2n12-3010.txt содержит описания  всех оптимальных параметрически задаваемых регулярных графов $R(N,3,2)$ степени $v=3$ и $s=2$ классов вершин $12\le N\le 3010$. 

The file rgraphs_v3s2n12-3010.txt contains descriptions of all optimal, parametrically defined regular graphs $R(N, 3, 2)$ with degree $v=3$ and $s=2$ vertex classes, for $12 \le N \le 3010$.
