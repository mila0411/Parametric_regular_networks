Файл rgraphs_v3s2n12-3010.txt содержит описания оптимальных параметрически задаваемых регулярных графов $R(N,3,2)$ степени $v=3$ и $s=2$ классов вершин для четных  $12\le N\le 3010$ - числа вершин. Формат файлов: N — количество вершин (порядок графа), v — степень вершин, s — количество классов, D — диаметр, AD — среднее расстояние, T — время поиска (с), P — количество используемых процессов, L — списки оптимальных образующих.

The file rgraphs_v3s2n12-3010.txt contains descriptions of optimal, parametrically defined regular graphs $R(N, 3, 2)$ with degree $v=3$ and $s=2$ vertex classes, for even number of nodes $12 \le N \le 3010$. Files format: N - number of nodes (order of a graph), v - degree of nodes, s - number of classes, D - diameter, AD - average distance, T - time of search (sec), P - number of used processes,  L - lists of optimal generators.
